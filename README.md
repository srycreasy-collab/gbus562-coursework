# gbus562-coursework
Coursework for GBUS562

## About
This repository holds coursework for GBUS 562, a course on AI language models. It includes assignments, notes and projects on how large language models work and how they can be used in business.

## Weekly work

### Week 01
- **[Connect Four](week-01/connect4.html)**: a browser version of the classic game in a single HTML file. You can play against the computer at three difficulty levels (easy, medium or hard), or switch to two-player mode and take turns on the same device. It keeps score, alternates who goes first, and works with a mouse, touch or keyboard. Open the file in any web browser to play.
